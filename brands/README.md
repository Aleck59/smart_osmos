# Фирменные изображения

Иконка и логотип интеграции Smart Osmos.

| Файл | Размер | Назначение |
|------|--------|------------|
| `icon.png` | 256×256 | иконка интеграции |
| `icon@2x.png` | 512×512 | то же для экранов hDPI |
| `logo.png` | 509×256 | логотип для светлой темы |
| `logo@2x.png` | 1021×512 | то же для экранов hDPI |
| `dark_logo.png` | 509×256 | логотип для тёмной темы |
| `dark_logo@2x.png` | 1021×512 | то же для экранов hDPI |

Капля воды с тремя горизонтальными полосами — ступенями очистки.
Иконка одинаково читается на светлом и тёмном фоне и остаётся узнаваемой в 32 px.

## Как пересобрать

```bash
pip install pillow
python3 tools/make_icon.py --font /путь/к/Roboto-Bold.ttf
```

Скрипт рисует всё с четырёхкратным суперсэмплингом и сам обрезает пустые поля
логотипа, как того требует спецификация Home Assistant.

## Чтобы иконка появилась в Home Assistant

Home Assistant и HACS берут изображения не из репозитория интеграции, а из
общего каталога [home-assistant/brands](https://github.com/home-assistant/brands).
Пока домен там не зарегистрирован, интерфейс показывает заглушку.

Порядок действий:

1. Сделать форк `home-assistant/brands`.
2. Скопировать файлы в `custom_integrations/smart_osmos/`
   (именно `custom_integrations`, а не `core_integrations` — интеграция кастомная).
3. Открыть pull request.

После вливания изображения раздаются по адресу
`https://brands.home-assistant.io/smart_osmos/icon.png` и подхватываются
автоматически — менять что-либо в самой интеграции не нужно.
