# Smart Osmos H2

Прошивка ESPHome для контроля бытового обратного осмоса на плате **ESP32-H2 Super Mini**
и интеграция для Home Assistant.

Устройство считает объём воды двумя расходомерами, измеряет TDS, ведёт ресурс пяти
ступеней очистки, показывает всё на маленьком OLED и управляется **одной кнопкой**.
Wi-Fi у ESP32-H2 нет, поэтому связь и обновление прошивки идут по Bluetooth LE.

* Совместимо с мобильным приложением из проекта [VGCH/smart_osmos](https://github.com/VGCH/smart_osmos) —
  UUID сервиса и формат JSON сохранены один в один.
* Home Assistant подключается по BLE через интеграцию из этого же репозитория (HACS).
* Обновление прошивки — по BLE, через внешний компонент [`esp32_ble_ota`](https://github.com/slynn1324/esp32_ble_ota).

## Состав репозитория

```
esphome/
  osmos-h2.yaml                 ← основной файл прошивки (все пины — в начале)
  components/smart_osmos/       ← внешний компонент: расчёты, хранение, BLE-протокол
custom_components/smart_osmos/  ← интеграция Home Assistant (устанавливается через HACS)
docs/WIRING.md                  ← подключение и питание
docs/PROTOCOL.md                ← описание BLE-протокола
.github/workflows/              ← сборка прошивки и проверка интеграции
```

## Оборудование

| Компонент | Модель |
|-----------|--------|
| Плата | ESP32-H2 Super Mini |
| Расходомеры | 2 × YF-S402B |
| Качество воды | TDS Meter v1.0 (аналоговый) |
| Дисплей | OLED 0.91", SSD1306, 128×32, I²C |
| Управление | одна тактовая кнопка |

Распиновка, требования по питанию и варианты подключения кнопки — в
[docs/WIRING.md](docs/WIRING.md).

## Быстрый старт

```bash
pip install esphome
esphome compile esphome/osmos-h2.yaml     # проверить и собрать
esphome upload esphome/osmos-h2.yaml      # первая прошивка — по USB
```

Дальше прошивать можно по воздуху:

```bash
pip install bleak
python3 esp32_ble_ota_upload.py --device "SMART OSMOS" \
        --password "OeN12345" firmware.ota.bin
```

Скрипт `esp32_ble_ota_upload.py` лежит в репозитории компонента
[slynn1324/esp32_ble_ota](https://github.com/slynn1324/esp32_ble_ota).

Собранная прошивка также появляется артефактом каждой сборки GitHub Actions
и прикрепляется к релизам.

### Настройка под себя

Всё, что обычно требуется поменять, собрано в блоке `substitutions` в самом
начале `esphome/osmos-h2.yaml`: номера пинов, тип подключения кнопки, импульсы
на литр, ресурс каждой ступени, имя BLE-устройства и пароль обновления.

## Экраны

Дисплей 128×32 разбит на шесть страниц. По краям видны стрелки — они показывают,
что страница есть слева или справа.

| # | Экран | Что показывает |
|---|-------|----------------|
| 1 | Фильтры | Пять ступеней в ряд: номер и под ним шкала остатка ресурса |
| 2 | TDS | Слева крупно текущее значение и среднее за сутки, справа график за 24 ч |
| 3 | Расход | Две колонки — водопровод и чистая: текущий расход (л/мин) и объём за минуту |
| 4 | Статистика TDS | Минимум / среднее / максимум за сутки и коэффициент прочистки |
| 5 | Объём и замены | Суммарные объёмы и даты замены ступеней (листаются парами) |
| 6 | Настройки | Список настроек (компонент `graphical_display_menu`) |

### Индикация ресурса

| Остаток | Поведение шкалы |
|---------|-----------------|
| больше 20 % | обычная заполненная шкала |
| меньше 20 % | номер и шкала мигают с частотой 0.25 Гц |
| меньше 5 % | мигают с частотой 0.5 Гц, шкала пустая и перечёркнута наклонной линией |
| 0 % | не мигает, шкала перечёркнута крест-накрест |

### Управление одной кнопкой

| Жест | На экранах 1–5 | В меню настроек |
|------|----------------|-----------------|
| Короткий клик | следующая страница | следующий пункт; при правке — увеличить значение |
| Двойной клик | предыдущая страница | отмена правки, выход из подменю, выход из меню |
| Удержание (>0.7 с) | — (на экране 6 открывает меню) | войти в пункт / подтвердить значение |

Через **10 минут** без нажатий дисплей гаснет. Первое нажатие после этого только
будит экран и не выполняет действие. Таймаут настраивается в меню.

### Что есть в меню настроек

* **Калибровка** — калибровка расходомера чистой воды «на 1 литр», ручной ввод
  импульсов на литр для обоих расходомеров.
* **Ресурс, л** — ресурс каждой из пяти ступеней.
* **Замена фильтра** — отметить замену ступени (обнуляет счётчик и ставит дату).
* **TDS** — множитель и смещение калибровки, сброс суточной статистики.
* **Дисплей** — таймаут гашения и яркость.
* **Сервис** — наработка, суммарные объёмы, обнуление счётчиков.

### Калибровка расходомера «на 1 литр»

1. Меню → **Калибровка** → **Пуск (пролить 1 л)**.
2. Пропустить через линию чистой воды ровно один литр (мерной ёмкостью).
3. **Готово — 1 л налит**. Прошивка посчитает импульсы на литр и сохранит их.

То же самое доступно из Home Assistant кнопками «Калибровка: старт» и
«Калибровка: налит 1 литр».

## Home Assistant

### Установка через HACS

1. HACS → ⋮ → **Custom repositories**.
2. Добавить `https://github.com/Aleck59/smart_osmos`, категория **Integration**.
3. Установить **Smart Osmos** и перезапустить Home Assistant.
4. Контроллер найдётся сам через Bluetooth; если нет — «Добавить интеграцию» → Smart Osmos.

Нужен рабочий Bluetooth-адаптер (встроенный, USB или ESPHome Bluetooth Proxy
в зоне действия).

### Что появится

* **Датчики**: TDS (текущий, минимум/среднее/максимум за сутки), расход по обеим
  линиям, объём за минуту, суммарные объёмы, коэффициент прочистки, эффективность,
  а по каждой ступени — остаток ресурса, пропущенный объём и дата замены.
* **Двоичные датчики**: связь, идёт калибровка, ресурс на исходе, требуется замена.
* **Настройки**: ресурс каждой ступени, импульсы на литр, калибровка TDS.
* **Кнопки**: отметить замену ступени, обнулить счётчики, сбросить суточную
  статистику, управление калибровкой.

Интеграция раз в час отправляет устройству время Home Assistant — именно оттуда
контроллер узнаёт дату, которую показывает на экране замен.

## Как считаются величины

**Объём.** Импульсы расходомера делятся на калибровочный коэффициент
(имп/л). Для YF-S402B `F = 98 · Q(л/мин)`, то есть 5880 импульсов на литр —
это значение по умолчанию, точное получается калибровкой.

**TDS.** Формула DFRobot с термокомпенсацией, как в исходном проекте:

```
ec  = U / (1 + 0.02 · (T − 25))
TDS = (133.42·ec³ − 255.86·ec² + 857.39·ec) · 0.5 · множитель + смещение
```

**Ресурс ступени.** Остаток = `100 − пропущено·100/ресурс`. Ступени 1–4 считают
входной объём, ступень 5 — объём чистой воды (это настраивается).

**Коэффициент прочистки** — отношение объёма чистой воды к водопроводной, в процентах.
