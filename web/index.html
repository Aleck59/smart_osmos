Smart Osmos — прошивка по Bluetooth

Обновление контроллера ESP32-H2 прямо из браузера, без проводов и без Python.

Браузер не поддерживает Web Bluetooth.

1. Файл прошивки

Нужен именно firmware.ota.bin — не firmware.bin и не firmware.factory.bin. Его выкладывает сборка GitHub Actions в артефакт smart-osmos-firmware.

2. Устройство

Имя и пароль заданы в substitutions файла osmos-h2.yaml (ble_name и ota_password).

Дополнительно

Уменьшите до 180, если запись обрывается с ошибкой.

Больше — быстрее, но растёт риск переполнения стека BLE.
